# Kivoo Streaming

Sitio estatico de una sola pagina.

## Estructura

```text
Streaming/
|- index.html              # Punto de entrada y estructura de la pagina
|- assets/
|  |- css/
|  |  `- main.css          # Estilos y diseno responsivo
|  `- js/
|     |- site.js           # Interacciones generales y animaciones
|     `- combo-builder.js  # Logica del configurador de combos
`- .vscode/                # Configuracion local del editor
```

Abre `index.html` en el navegador o publicalo como un sitio estatico. No requiere dependencias ni proceso de compilacion.
