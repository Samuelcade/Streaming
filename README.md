# Kivoo Streaming

Página de streaming creada con React, JavaScript, CSS y Vite.

## Requisitos

Node.js 20.19+ o 22.12+ y npm.

## Desarrollo

```bash
npm install
npm run dev
```

Abre la dirección local que aparece en la terminal. Para generar la versión de producción ejecuta `npm run build`; los archivos se crean en `dist/`. Puedes probar esa versión con `npm run preview`.

## Estructura

```text
src/
├── components/       # Secciones y configurador de combos
├── data/platforms.js # Catálogo, precios y enlace de contacto
├── App.jsx           # Composición de la página
└── main.jsx          # Entrada de React
assets/css/main.css   # Estilos del sitio
```
